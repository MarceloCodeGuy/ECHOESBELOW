# Echoes Below

An original, Undertale-inspired 2D RPG experiment built with vanilla HTML5 Canvas and JavaScript.

## Run
Open `index.html` locally, or enable GitHub Pages for the repository.

## Controls
- Arrow keys / WASD: move
- Enter / Space: interact, advance dialogue
- Z: confirm
- X / Escape: back
- In battle: Arrow keys + Z

## Current playable systems
- Intro sequence
- Room-to-room overworld
- NPC dialogue
- Encounters
- Turn-based combat
- ACT / ATTACK / ITEM / MERCY choices
- Mercy and defeat consequences
- Save/load through localStorage
- Three route variables
- Three ending framework
- Shops and inventory
- Quest/flag system
- Six planned story regions

## Roadmap
The data files are deliberately separated from the engine so additional rooms, dialogue, enemies,
quests, puzzles, music and bosses can be added without rewriting the core game.
